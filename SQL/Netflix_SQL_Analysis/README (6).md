## Overview

This project analyzes the Netflix Movies and TV Shows dataset using **MySQL**. It focuses on solving real-world business questions and demonstrates SQL concepts ranging from basic queries to advanced analytical techniques.

## Objectives

- Analyze the distribution of Movies and TV Shows.
- Identify the most common content ratings.
- Explore content by release year, country, genre, and duration.
- Perform director- and actor-based analysis.
- Generate business insights using SQL.

## Dataset

The dataset contains information about Netflix content, including:

- Show ID
- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

**Source:** Netflix Movies and TV Shows Dataset (Kaggle)

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- JSON_TABLE()
- String Functions
- Date Functions



## Key Insights

The SQL queries in this project help uncover insights such as:

- Distribution of Movies and TV Shows.
- Most common content ratings by content type.
- Country-wise and year-wise content analysis.
- Genre, director, and actor-based trends.
- Content categorization using text analysis.
- Business insights through SQL aggregations and window functions.

## Database

- MySQL 8.0+

## Conclusion

This project demonstrates how SQL can be used to analyze a real-world dataset and extract meaningful insights. It showcases essential SQL concepts commonly used in data analytics, business intelligence, and technical interviews.
